# Usage during development

This is an unfinished installer. Use the [current plan](../CURRENT-PLAN.md) and [scope registry](../requirements/current-scope.json) to distinguish implemented code from actual target/account acceptance. Do not run installation on the development Mac.

On the identified authorized Pi, the lifecycle CLI provides plan/doctor/status/install/resume entrypoints; a command being parsed does not establish that every component is operational. Select core-only and the actual unprivileged owner/home/storage after inventorying existing services. Preserve Codex authentication by protected reference and retain official PM Python3.14. Missing dependency/account/license/native support must report unavailable and a concrete resume action.

Jarvis is the responsive client for finite owned conversation/chat/history/stop adapters. Public access requires the existing owned Cloudflare Access OTP/binding and all JWT/stream protections; a private chat probe does not enable or qualify public use. Family identities and tools/memory require explicit server grants and actual isolation evidence.

Additional integrations, Bots groups/relay, jobs, browser, attachments, voice and full Resources are enabled individually after real qualification. Provider subscription/API eligibility is separate from login; zero additional metered spending remains default. Required GLM-5.2 and Coral tests are separate, with no large download or replacement model implied.

Finished installer quick-start commands and stable supported platform/capability lists are a release task after actual end-to-end qualification.
