# MCP connectivity

MCP uses Hermes-supported server records and credential references. Initialize, tool discovery and calls have bounded deadlines. Unknown schemas, revoked credentials and missing account eligibility fail closed. Selected-resource adapters narrow tools to harmless reads and return results through privacy policy.

Figma uses the official remote MCP and one selected file. RevenueCat uses its official remote MCP and one selected project with list/read operations only. Google official MCP services remain unavailable until preview eligibility is verified and a service/resource is selected. The taylorwilsdon option is a separately labeled community server that requires source/command review. Home Assistant connects to an existing documented MCP endpoint and selected entities; setup does not create or replace HA. Playwright uses an official local package under a host-supervised process binding with a fresh browser profile and loopback-only fixture policy. A profile is not an OS sandbox; process/network isolation remains dependent on the host custody enrollment and Pi verification.

Fixture success does not establish live account authentication, external reachability, ARM64 browser support or selected-resource verification. Setup performs no message, document/calendar, Figma, RevenueCat or Home Assistant mutations.


Google Workspace endpoints and effect classifications were checked against Google's primary [setup guide](https://developers.google.com/workspace/guides/configure-mcp-servers) and per-tool references: [Gmail](https://developers.google.com/workspace/gmail/api/reference/mcp), [Drive](https://developers.google.com/workspace/drive/api/reference/mcp), [Docs](https://developers.google.com/workspace/docs/api/reference/mcp), [Sheets](https://developers.google.com/workspace/sheets/api/reference/mcp), [Calendar](https://developers.google.com/workspace/calendar/api/v3/reference/mcp), and [People](https://developers.google.com/people/api/mcp). These services require Developer Preview program membership, a Cloud project, and the relevant Workspace API and MCP API enabled. The client selector keys match the documented JSON input fields (for example `messageId`, `fileId`, `spreadsheetId`, `calendarId`). The People profile tool is not exposed because it has no selected-resource parameter; contact search is bounded to the exact selected query. No caller-provided boolean establishes eligibility. The protected host currently has no signed account-eligibility claim, so Google MCP calls remain unavailable until that enrollment evidence exists and OAuth is verified.
