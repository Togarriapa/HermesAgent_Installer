# MCP connectivity

MCP uses Hermes-supported server records and credential references. Initialize, tool discovery and calls have bounded deadlines. Unknown schemas, revoked credentials and missing account eligibility fail closed. Selected-resource adapters narrow tools to harmless reads and return results through privacy policy.

Figma uses the official remote MCP and one selected file. RevenueCat uses its official remote MCP and one selected project with list/read operations only. Google official MCP services remain unavailable until preview eligibility is verified and a service/resource is selected. The taylorwilsdon option is a separately labeled community server that requires source/command review. Home Assistant connects to an existing documented MCP endpoint and selected entities; setup does not create or replace HA. Playwright uses an official local package with a fresh sandboxed profile against loopback fixtures, never personal browser state or a disabled sandbox.

Fixture success does not establish live account authentication, external reachability, ARM64 browser support or selected-resource verification. Setup performs no message, document/calendar, Figma, RevenueCat or Home Assistant mutations.
