# Fixed local service connector

HI07 implementation is provided by `hermes_installer.service_connector`. The protected root daemon owns the TCP socket and returns only a bounded JSON stream receipt with opaque `connector_id`, service generation, monotonic expiry, maximum frame size, and remaining byte budget. The worker uses `ServiceConnectorClient.open(...)` and the typed `ConnectorStream.read(max_bytes)`, `write(data)`, and `close()` methods through its authenticated `AuthorityClient`.

The only routes in the source catalog are `xpra-native/xpra-http`, `xpra-native/xpra-websocket`, and `colibri-main/colibri-openai-v1`. Root resolves each exact profile, enrollment, target, route, and generation to a registered live process handle, then enters its protected network namespace and connects to the fixed loopback endpoint. Callers cannot provide a process ID, address, URL, port, namespace selector, or socket descriptor. Service namespace and process PIDFD leases remain root-owned for the stream lifetime.

Open, read, write, and close use separate one-use authority grants against the same exact target ID. Open binds enrollment, generation, route, session, action and deadline in the canonical body; grant/context metadata remains outside the digest. Every stream call binds the peer UID/PID, source-lineage hash, route, target, session, frame sequence and fresh operation grant. Frames are limited to 1 MiB; a stream is limited to 16 MiB and 60 seconds. The watchdog closes both directions and releases the retained process/namespace lease at expiry or shutdown. A stale generation, exited process, peer/session mismatch, replay, arbitrary route, cancellation, exhausted budget or stream-capacity denial occurs before additional socket bytes are relayed.

The connector transports bounded bytes only on its enrolled service channels. The Xpra gateway must continue to apply its own GET/HEAD asset allowlist and binary WebSocket handling after JWT, Access policy, origin and active-lease checks; the Colibri caller must remain on its designated OpenAI-compatible API channel. This connector does not enroll memory or MCP endpoints, authenticate a Colibri API, or establish native Desktop acceptance. Adding any other service requires a separate fixed route and protocol review.

`tests/contracts/test_service_connector.py` uses a local TCP listener to verify an actual open/write/read effect, plus unknown-route, stale-generation and foreign-peer denials. These tests are fixture evidence; protected root daemon installation, Linux namespace/cgroup effect tests, gateway protocol restrictions, and ARM64/Pi service acceptance remain separate and pending until their respective evidence jobs pass.
