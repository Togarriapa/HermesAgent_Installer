# Browser access to Hermes Desktop (RT-F01..RT-F03, AC13..AC15)

Remote access publishes one explicitly chosen hostname through a dedicated Cloudflare Tunnel. The hostname prompt starts blank, with no default domain. Setup requests allowed email addresses and a scoped Cloudflare management API token through hidden input, or resolves an approved secret reference. It discovers active authorized zones and the account attached to the selected zone. Management credentials are setup-only. A separate minimum-read Access-policy credential reference is required for activation. Only an isolated verifier custodian under its own installer-owned service identity resolves it; the browser gateway receives a fixed AF_UNIX decision interface and never sees the secret or resolver. The verifier runs under a distinct non-root service UID from the gateway. It performs bounded GET-only reads of the exact owned Access app (resource UUID and its separate `aud` tag), every policy page, and the OTP identity provider, then repeats the reads to reject observed in-flight changes. Requests bind the signed JWT, principal, profile, config digest, action, session, peer UID and one-use nonce. Decisions fail closed after a cancellable nine-second read deadline. The read secret remains out of the gateway, Desktop, cloudflared, command arguments, environment, logs and checkpoint data. Until that reference is configured with account Access-application and policy read permissions, remote access remains unavailable. Missing account enrollment, permissions, certificate coverage, Pi runtime, or native isolation leaves access pending with a concrete resume step. Setup does not purchase a plan or broaden the requested scope.

Provision a dedicated installer-owned tunnel, exact DNS hostname, Cloudflare Access self-hosted application, email one-time-code identity provider, and allow-email policy. Reuse only compatible resources with verified ownership. Conflicts stop before mutation. Write an ownership journal before effects; after ambiguous API failures, read and reconcile the intended resource before retrying. Access and the origin gateway must pass readiness before DNS and tunnel ingress activate. The catch-all ingress returns 404.

Only the official Hermes Desktop Linux ARM64 app is streamed through a dedicated unprivileged Xpra seamless session and pinned minimal HTML5 client. The bridge does not attach to the host desktop. Server controls disable shell, command/session creation, file movement/opening, clipboard, printing, audio, camera, device access, DBus, diagnostics and unused proxy transports. Server window rules deny unmatched windows. Hidden client controls do not count as enforcement. Verify Electron renderer sandbox state on every launch; a no-sandbox fallback leaves remote access unavailable.

The loopback gateway allows only the pinned HTML5 client entrypoint, bundled JavaScript/CSS/icon assets, session, renewal and WebSocket routes; it denies Xpra connect, clipboard, digest, MITM, service-worker and diagnostic pages. The stock Xpra server menu is removed from presentation, while the server disables its corresponding operations independently; hiding controls is never the authorization boundary. HTTP asset reads and concurrent upstream work have fixed size, time and concurrency bounds. Validate Cloudflare Access RS256 JWTs against the fixed team issuer, exact one-application audience (Cloudflare’s singleton `aud` array is accepted; mixed audiences are rejected), bounded HTTPS JWKS, time claims and explicit email allowlist before sending any bytes or creating a session. Check exact hostname and browser Origin and bind each stream to one principal/profile. Server leases cap at 60 seconds and the watchdog checks no slower than five seconds. Renewal uses a separate fresh Access-protected HTTP request and one-use socket challenge; stream frames cannot renew themselves. The isolated verifier re-reads application, all policy pages and the selected OTP identity provider for each issue/open/renew decision; missing, changed, broadened, ambiguous, or unavailable state denies. A lease deadline is anchored to the start of the fresh authorization read and is at most 60 seconds and no later than JWT expiry, so verifier latency cannot extend it. Existing streams close at that deadline under the watchdog. This does not claim immediate forced closure following an administrative policy edit without verified propagation evidence, or revocation of a still-valid JWT without a tested revocation source. Explicit logout/revoke and policy removal are separate acceptance probes. Edge token expiry is not assumed to close an upgraded socket.

The setup management token is setup-only. Runtime cloudflared reads a dedicated tunnel token from a protected file; neither token enters command-line arguments, process environment, logs, evidence, or Desktop profile files. Disable, rollback, and uninstall reconcile resource IDs from the journal and remove only resources created by the installer.

## State and evidence

Configured means explicit hostname, zone, allowed emails and secret reference validate. Pending account means API permissions or Zero Trust enrollment are missing. Pending target means live Pi/account behavior remains unverified. Active requires Access and origin readiness followed by ordered route activation. Code fixtures do not prove Pi acceptance.

Target acceptance records exact Pi/account identity, unauthorized HTTP and WebSocket denials before bytes/input, genuine Desktop pixels/control, blocked foreign-window and command attempts, Electron sandbox status, live socket expiry, policy-removal renewal denial and owned-resource recovery. Do not record JWTs, API or tunnel tokens, email codes or credential values. Use the installer workflow configure/resume and doctor/verify commands with the remote_desktop hostname, allowed_emails and management_token_ref; resolve the reference through the installer credential interface.

Live account setup is authorized by the installation choice once valid scoped credentials are supplied. Development and fixture runs do not mutate Cloudflare or activate a hostname.
