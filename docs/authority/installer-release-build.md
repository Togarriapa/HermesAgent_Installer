# Root installer release build inputs

The stage-zero builder selects the authorized repository/candidate explicitly, acquires exact reviewed source/runtime/catalog/template inputs under bounded TLS/digest checks, and retains a protected source receipt. Executable schemas/capture/templates/license inputs live in contracts/ and remain independent from the single current plan. Obsolete plans are not required at current branch HEAD.

Verify no-follow regular files, complete closure, exact hashes/sizes/modes/roles, source ownership and current object identity. Stage reviewed modules and isolated interpreter/dependencies into an owned generation. The output manifest binds every actual release member and role closure; an opaque one-use receipt owns the staged directory. Caller paths, manifests, arbitrary output bytes, shell commands and role maps never confer root authority.

Installed publication verifies live selected root process/interpreter/imported modules and atomically compare-and-swaps the owned deployment pointer, preserving prior working state. Corrupt/foreign/unreadable predecessor pointers fail closed; verified predecessor recovery is distinct from current-source planning. No Git tag movement/history rewrite is part of the migration.

Actual Linux ARM64 provisioning/reexec/service effects, adoption/restart/rollback and failure containment need exact Pi evidence. Source editing, receipt fixtures and closure checks are not installed target acceptance. Follow [current core lifecycle design](../../openspec/changes/jarvis-core-platform/design.md) and [operations](../operations.md).
