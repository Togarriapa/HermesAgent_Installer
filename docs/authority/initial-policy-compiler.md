# Initial root policy compiler

`hermes_installer.authority.initial_policy_compiler` owns the finite renderer for the immutable `installer-bootstrap-compiler-template-v1` source bytes (v30, SHA-256 `27854f8f8c67ce42832f020dbfd96512607e39576b27e484598ff397cb9432e5`). It rejects altered bytes, duplicate JSON members, unknown binding expressions, malformed observed values, and every unresolved required binding. Its inputs are rooted in the installed release and root registries; setup choices never carry policy rows, paths, IDs, runtime hashes, or authority rules.

The verified principal is the sole compile-time identity value. NSS IDs are allocated during the prepared transaction, while PM and native executable pins require actual output receipts. Until those receipts exist, the policy remains prepared and its service record set is empty. No identity, executable hash, namespace, or native reference is synthesized. A root-issued namespace observation and the complete strict policy/publication serializer are still required before `compile_initial_policy` can store a publication; the renderer currently fails closed when that observation is absent.

The dormant prepared authority base uses the separate v63 immutable template `installer-prepared-authority-base-template-v1` (SHA-256 `da20ce244bbbc771dfaf463d8ce8914d87b6eb9898228952a55681e1aa6fb953`). It binds only the verified authority-key receipt ID and an exact, digest-validated empty service-generation snapshot joined to the stage-zero root journal receipt. Every authority map, including Authentik policy, remains empty; this base cannot authorize worker effects. Active authority retains its separate strict policy schema.

This renderer supports existing first-setup work under `BD-F01`, `LC-F03`, and `HI-T01`; it does not establish the Pi, account, or runtime acceptance gates. Stage-zero session creation, the complete policy publication document, atomic publication, and the one-use handoff remain owned by the root setup registry and policy publisher described in the live contract. No root installer or target was executed on the development Mac.
