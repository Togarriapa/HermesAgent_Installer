## Architecture decisions

Thin shell plus typed Python orchestrator, injected bounded command/network/filesystem interfaces and durable ownership/checkpoint state. Reviewed version-aware adapters, isolated environments, actual policy mediation, one config source, generated unprivileged services, atomic generations. Canonical Hermes official PM runtime/toolchain is separate from installer Python. Existing data/settings/credentials/overlays/unrelated services survive adoption/update/rollback/uninstall. Read each change's design for concrete module interfaces and migration/failure handling.

Privacy/capability/budget policy wraps initial/retry/fallback/system/tool/background/extraction/embedding dispatch. Zero additional metered budget; no private-to-ineligible-free leak. Host policy intersects registry/account capability, real broker isolation and fresh Authentik lookup; prompt/persona/profile separation is insufficient. Hermes alone binds user channels; correlated internal recruitment preserves evidence/dissent and separate state. No external homelab target is enrolled by this plan.

GLM-5.2 artifact149 files/429276220139bytes and MTP digests are pinned; implement resumable integrity/space/ARM64/service/benchmark path without performing a huge download here. Physical performance is unmeasured. Coral requires real delegate-used official sample inference. Skill tree helpers/assets/root refs and host hooks get distinct operational evidence. Independent apps remain isolated/on-demand. Official MCP tests are harmless selected-resource reads; Playwright uses local fixture screenshot and retained browser sandbox. Memory requires synthetic fact extraction/restart/new-session retrieval, one owner and separate private embedding/extraction eligibility.
