# Why

The user owns Resources and requires a self-contained installer that survives deletion of that upstream. Existing pinned-fetch planning does not guarantee packaged content, actual native materialization or full referenced-source enrichment.

# What Changes

Add RB01–RB05 and AC16 through plans/amendments/2026-10-09-resources-bundle-v1.md and planning/resources-bundle-amendment.json. Bundle exact owned version2.3.1 tree; compile all eight resource kinds into native Hermes/adapters; enrich complete compatible referenced content and hooks; prove offline readiness, conflict preservation and recovery. Preserve all211 original requirements and frozen baseline.

- `resources-bundle-native-enrichment`: offline owned Resources packaging, native materialization and effectful enriched workflows.

## Modified Capabilities

None; this additive capability refines pending registry requirements without publishing unimplemented canonical behavior.
